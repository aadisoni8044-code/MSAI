# Change Log

All notable changes to the "Keyboard Sound" extension will be documented in this file.

## [1.0.0] - Initial Release

- Initial release of **Keyboard Sound** by **Aadi Soni**.
- Realistic mechanical keyboard audio playback while typing in VS Code.
- Ultra-low latency sound engine powered by Web Audio API buffer synthesis & pre-loaded audio.
- Support for multiple sound packs: `mechanical`, `thock`, and `typewriter`.
- Specialized sounds for `Space`, `Enter`, `Backspace`, `Tab`, and `Delete`.
- Real-time volume controls (0% to 100%, preset levels Mute, Low, Medium, High, Very High).
- Quick toggle command and interactive Status Bar indicator (`🔊 Keyboard Sound: ON` / `🔇 Keyboard Sound: OFF`).
- Sound test command (`keyboardSound.testSound`) for quick audio verification.
