SYLVAN VEIL: ANCIENT CHRONICLES

A dark fantasy side-scrolling platformer engine created with Vanilla HTML5, CSS3, and JavaScript.

Game Design & Engine Architecture

Built with Web Audio API Synthesizer, Fixed Timestep Physics Loop, Vector Canvas Rendering, and Multi-layer Parallax Renderer.

Atmosphere & Visual Art

Inspired by deep dark teal forest compositions, glowing fireflies, ancient hanging vines, and ethereal blue-green mist.
